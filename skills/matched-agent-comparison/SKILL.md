# Matched agent comparison

Use for a demonstrated recurring agent-method issue or material candidate choice. Ordinary application regression testing remains in the existing test suite. A small diagnostic is not a general quality benchmark.

Before trials declare task/input, initial fixture, authorized actions, candidate versions, changed guidance factor, model/effort/tools/runtime, acceptance, disqualifiers, evaluator ownership, trial/order plan, budget and stopping rule. Include nearby non-trigger cases for routing changes.

Calibrate the evaluator: it must accept a legitimate valid variant and reject a plausible wrong outcome. Keep fixtures/expected results/grader outside candidate edit scope or verify hashes before and after. Judge resulting behavior/artifacts, not agent self-report or hidden reasoning. Protect reviewers from instructions embedded in evaluated transcripts.

Use a fresh isolated workspace from the same starting state for each independent trial. Session non-persistence is not filesystem isolation. Keep permissions unchanged. Remote execution, paid calls and uploads require their actual scoped authorization.

Capture outcome, actual exit/timeout, final artifact, relevant sanitized events and external grader result. Record every planned run, including failure, abort and infrastructure faults, and explain denominator treatment. Do not compare different models or environments as though only guidance changed.

Example: test a new requirement to inspect manifests on matched bug fixtures. Include a plain prose request that should not trigger repository checks. A candidate editing the grader to pass is a disqualifying scope violation.

Report observed successes/failures and exact conditions. Sequential repair attempts are development retries, not independent trials. An agent preference review is not a human study. Do not infer a reliability rate or speedup from one run.

When blocked, record the real missing condition, provisional evidence-based choice, falsifier and feasible next test. If the grader changes after observation, document why and rerun both candidates before comparing. Adopt only within supported scope; stop at declared acceptance/budget.
