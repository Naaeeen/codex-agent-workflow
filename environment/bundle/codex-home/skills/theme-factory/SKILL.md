# Theme palette library

Use this as a visual reference, not a mandatory approval step. For complete
website/slide/document creation, keep the relevant host authoring workflow.

- If the user specified a theme, reference or design system, follow it.
- If they delegated visual choice, select a suitable palette and continue.
- Ask only when an unresolved choice materially changes the intended result.
- Offer theme-showcase.pdf when comparing palettes is useful; do not require
  the user to view it or reconfirm an already-authorized choice.

the actual output format. A custom palette is fine when none fits. Check the
rendered artifact through its authoring workflow; theme selection alone does
not verify layout, legibility or accessibility.
