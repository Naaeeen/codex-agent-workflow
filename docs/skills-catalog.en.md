# Installed Skill catalog and portable set

Inventory date: 2026-11-10. The evidence is actual `SKILL.md` files in the two user roots and the client's `.system` child directory. Only metadata and relevant selected instruction bodies were read; auth, session databases, private chats and memory were excluded. Plugin cache contents and other session-provided plugin Skills are outside these filesystem counts.

Aliases: A = user `.agents/skills`; C = user `.codex/skills`; S = C's `.system`. There are **46 A + 16 C + 5 S = 67 actual Skill files**. Paths are intentionally relative aliases.

“Body read” means this audit read the instructions. “Metadata inventoried” confirms the file and its routing description. Historical invocation or success needs separate task evidence. Session exposure is also separate: a `review-agent` folder in S does not establish a callable role with that name in this session.

The full environment now includes [62 user Skills](../environment/bundle/codex-home/skills/). See [per-Skill provenance and adaptations](../environment/portability.json) and [licenses](../THIRD_PARTY_NOTICES.md). The inventory below retains the original source-root classification. The six portable rewrites are the smaller project starter. The target client supplies its system Skills.

## Applying DAILY and LIBRARY

The installed `agent-sort` method classifies against repository evidence. DAILY means routinely relevant and readily discoverable for that project, not “load every body every session.” LIBRARY keeps material searchable without deleting it. React dependencies, TSX files and CI can justify frontend Skills as DAILY; a prose-only project does not need database and end-to-end test procedures loaded by default. Reuse the existing catalog before adding another router. Copying Claude directories, slash commands or hook names does not supply their runtime to Codex.

This catalog supports transparent selection, not blanket installation. Executable tools, account authorization and live service availability require their own checks.
